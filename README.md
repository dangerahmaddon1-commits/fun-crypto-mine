# Fun Crypto Mine

Separate, compliance-first rewards platform prototype.

## Current state
Static responsive MVP prototype only. It is not connected to authentication, advertising providers, offerwalls, mining infrastructure, payment processors or cryptocurrency wallets. No balances, earnings, payouts, mining output or subscription purchases are real.

## Proposed model
- Eligible advertising, offerwalls, surveys and sponsored tasks.
- Potential independently verified mining proceeds as a separate future module.
- Proposed allocation: 60% platform / 40% user reward pool from verified eligible net revenue, subject to published terms and provider rules.
- Premium subscriptions initially provide software features only; no guaranteed earning increase.
- Crypto payouts are disabled pending legal, provider, security and compliance approval.

## Launch gates
Do not accept deposits, sell mining contracts, issue tokens, activate paid subscriptions or process withdrawals until legal, licensing, tax, privacy, security, provider and operational requirements have been reviewed and approved. Never present virtual mining visuals as actual mining or promise fixed returns.

## Deploy
Static site entry point: index.html. Import this repository into a separate Vercel project and deploy the MVP branch for preview. No build command is required.

## Next milestones
1. Authenticated accounts and role-based access.
2. Immutable double-entry accounting ledger and reconciliation.
3. Approved provider adapters and signed, idempotent webhooks.
4. Fraud review, dispute handling and admin audit logs.
5. Subscription billing and crypto payout provider assessment after legal review.
